04 / ПОЛЕЗНО ЗНАТЬ

Перед установкой.

Приложение уже пишет в чат само?+

В 0.4.2 есть экспериментальная автоочередь для официального Android-приложения ChatGPT. Она включается через настройки доступа и запускается кнопкой «Старт» в выбранном чате. Веб-версия ChatGPT и работа с заблокированным телефоном в этот режим не входят. Совместимость с твоей версией ChatGPT нужно проверить первым коротким запуском.

Какие данные использует приложение?+

Команды, прогресс и технический журнал сохраняются на телефоне. В автоматическом режиме служба получает доступ к видимому тексту и кнопкам ChatGPT, чтобы проверять результат и отправлять следующие команды. Ответы не записываются в журнал. У Директора нет сетевого разрешения; отправленные сообщения обрабатывает сам ChatGPT. Доступ можно отключить в настройках Android.

Приложение не открывается или служба не работает — что делать?+

В 0.4.2 исправлена обнаруженная ошибка запуска главного экрана. Обнови приложение поверх установленной версии и открой его обычным значком. Если ошибка повторилась, открой Директор → О проекте → Диагностика запуска → Скопировать. Если вместо главного экрана появляется экран восстановления, кнопка копирования отчёта находится прямо на нём. После обновления выключи и включи службу один раз для повторной проверки. Исправление на realme ещё нужно подтвердить.

Скачивание зависло на 100% — что делать?+

Открой этот сайт в отдельном браузере, например Chrome, и нажми «Скачать для Android». Основная кнопка загружает файл прямо с сайта; запасная ссылка ведёт на GitHub. Проверь также папку «Загрузки»: файл мог уже сохраниться, хотя окно загрузки ещё не закрылось.

Скачивание с сайта решает блокировку установки?+

Сайт даёт прямую ссылку на файл. Это не подтверждение, что Android разрешит его установить. Если появляется блокировка, сохрани точный текст сообщения: нужно разобрать причину для конкретной сборки.

Как проверить скачанный файл?+

Контрольная сумма SHA-256 текущего APK:

fec8826fb09ca07ad82a0ac19baae9f81f40017b45e1f65f1a018cda656bffdb

Хеш помогает проверить совпадение файлов. Он не заменяет подпись APK или проверку работы приложения.
