# Директор 0.4.7-preview

Исправления повторно сообщённых ошибок: длинная приписка, отправка первого шага в DeepSeek и остановка перед следующим шагом.

## Изменения

- Отправка теперь всегда использует ровно текст команды. Старый сохранённый режим служебных отметок автоматически отключается, соответствующий переключатель удалён. Произвольный пользовательский текст не обрезается.
- Ранее вставленный черновик с припиской распознаётся только для очистки по нажатию «Убрать черновик». Незавершённая старая отправка не повторяется: её ответ проверяется вручную. Индекс, команды, счётчики и выбранное приложение сохраняются.
- Для доступных Android-элементов DeepSeek учитываются подсказки полей, вложенные редакторы и объявленные действия ввода/нажатия. Отсутствие текстового названия беседы не блокирует распознанное поле чата. Безымянная кнопка без признаков отправки не нажимается наугад.
- Короткий ответ может завершить шаг без замеченной кнопки Stop: нужен новый ответ с действиями, видимая отправленная команда и устойчивое состояние в нескольких наблюдениях. Одно молчание чата не означает успех.
- Обычная социальная реплика «А у тебя?» после приветствия не блокирует очередь. Просьбы уточнить задание, подтвердить действие, войти в аккаунт и неоднозначные вопросы сохраняют паузу.
- Автоматическая прокрутка после ответа сама по себе не останавливает следующий шаг. Проверяется сохранённый результат последнего шага, а не равенство всего видимого текста.
- Внутри живого процесса ожидание своего отправленного сообщения сохраняется при открытии плана и возврате в чат. После потери процесса сведения об отправке не выдумываются, автоматического повтора нет.
- Ответ, совпадающий с запрошенной цитатой («Напиши: Готово» → «Готово»), больше не должен отбрасываться только из-за совпадения слов с командой.

## Установка и первый запуск

Установи APK поверх предыдущего Директора. Package `app.hashqueue`, прежняя тестовая подпись, versionCode 13. Удалять приложение или планы для обновления не нужно.

Если остался черновик со старой припиской: открой его чат, нажми на панели «Убрать черновик», затем «Запустить». Если сообщение уже отправлено — проверь его ответ в плане; повторно отправлять его не нужно.

В плане под кнопкой открытия чата выбери «После ответа → Автоматически». Открой нужную беседу и нажми «Запустить» на панели. Сохранённые задержки остаются прежними. Для приёмки удобно проверить три команды: «Привет, как дела», «Посчитай 7 + 5», «Напиши: Тест завершён».

## Границы проверки

Сборка и автоматические проверки выполняются без эмулятора. Синтетические Android-деревья проверяют конкретные варианты доступного интерфейса, но не подтверждают работу на физическом realme. Если реальное приложение не предоставляет читаемое поле, действие отправки или законченный ответ, очередь остаётся на паузе с причиной. «Проверить чат» сохраняет диагностику структуры и действий без полной переписки.

Версия 0.4.6 остаётся отозванной. Это отдельное исправление 0.4.7, её релиз не восстанавливается.
