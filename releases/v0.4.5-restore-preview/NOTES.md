# Директор 0.4.5 — восстановленная сборка

По запросу владельца полностью возвращена база исходников 0.4.5. Экспериментальные изменения распознавания из 0.4.6 отменены. Релиз 0.4.6, его APK и тег удалены из GitHub; файл убран из текущего сайта. Старая ссылка сайта перенаправляется на восстановленную сборку. История Git не переписывалась.

Под кнопкой «Открыть ChatGPT / DeepSeek / Claude» появился выбор «После ответа»:
- **Вручную** — после распознанного ответа очередь ждёт нажатия «Следующий шаг» на панели.
- **Автоматически** — после распознанного ответа вставляет и отправляет следующий шаг с сохранёнными задержками.

Это тот же параметр, что в настройках; выбор сразу сохраняется и сам не запускает отправку. План, выбранное приложение, задержки, оформление, режим экрана и состояние панели не сбрасываются. Действие «Проверить текущий шаг вручную» остаётся отдельным способом разбираться с нераспознанным результатом.

## Установка поверх 0.4.6

Сборка называется `0.4.5-restore-preview`, внутренний `versionCode=12`, package `app.hashqueue`, подпись прежняя. Код выше 0.4.6 (11), чтобы Android принял восстановление как обновление. Удалять приложение для установки не требуется; планы не стираются кодом обновления. Фактическая установка на realme в этой среде не проверялась.

При сохранённой паузе до отправки открой чат и нажми «Убрать черновик» на панели, затем запусти шаг. Это очистит только совпадающий неотправленный текст. Если сообщение уже отправлено, повторно его не отправляй: проверь текущий шаг вручную в плане.

## Проверка

559 JVM-проверок и сценариев. Обе сборки скомпилированы, APK, подписи и manifest/DEX проверены. 12 ключевых файлов отправки, распознавания, очереди, хранения, оформления и WindowChrome побайтово совпадают с архивом 0.4.5. ConversationAnchor из 0.4.6 исключён.

Эмулятор не использовался. Новый выбор режима не меняет распознавание ответа: слишком быстрый или неясный ответ, пропущенное начало генерации и вопрос могут требовать ручной проверки. Полный цикл на физическом телефоне ещё не проверен.
