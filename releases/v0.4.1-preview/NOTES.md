# Директор 0.4.1-preview — запуск службы и диагностика

После включения доступа на realme Android 16 система показывала «Сервис работает некорректно». Скриншот подтверждает сбой службы, но не содержит исключения: точная причина на телефоне пока не установлена.

В этой сборке:
- Создание плавающей панели перенесено из подключения службы до открытия ChatGPT. На Android 12+ используется визуальный оконный контекст TYPE_ACCESSIBILITY_OVERLAY, на виджеты явно назначена тема.
- Частично запущенная служба больше не считается готовой. Ошибка останавливает отправку, не вызывает автоматических повторов и сохраняет технический отчёт.
- В журнале, разделе «О проекте» и карточке ошибки доступна «Диагностика запуска» с копированием.
- При ошибке запуска интерфейса появляется простой экран восстановления. Необработанный сбой сохраняется перед стандартным обработчиком Android; после следующего открытия доступен отчёт.
- Диагностика локальная: класс исключения и кадры стека без текста исключения, команд, ответов, имён файлов или серийного номера телефона. Новых разрешений нет.

Обновление: выключить службу автоочереди, установить APK поверх 0.4.0, открыть приложение обычным значком, затем включить службу для одного короткого теста. Удалять приложение или очищать данные не требуется. Application ID app.hashqueue и сертификат прежние, versionCode 6.

Проверено без эмулятора: 224 утверждения/сценария JVM, включая 13 проверок отсутствия пользовательского текста и ограничения размера отчёта; компиляция двух вариантов, подпись v2/v3, zipalign, целостность ZIP, compiled manifest/DEX. Проверки дерева ChatGPT синтетические.

Не проверено: реальный запуск и обновление на realme Android 16, отображение и работа панели, полный цикл команд в ChatGPT. Работу на телефоне и точную причину прежнего сбоя не подтверждаем до нового результата.
