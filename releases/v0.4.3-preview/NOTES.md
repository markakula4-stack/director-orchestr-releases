# Директор 0.4.3-preview — панель, которую контролируешь ты

В прежней версии панель снова появлялась после остановки: служба показывала её при очередной проверке чата. Теперь крестик × ставит очередь на паузу, убирает панель вместе с подсветкой и сохраняет скрытое состояние. Фоновая проверка чата при скрытой панели не выполняется. Вернуть её можно из приложения: **Настройки → Открыть ChatGPT и панель**. Возврат панели сам по себе не запускает отправку.

Что изменилось:

- Компактная панель с перемещением за заголовок. Стрелка раскрывает подробности и дополнительные действия.
- Мягкая синяя рамка экрана появляется только во время работы очереди. Рамка не перехватывает нажатия.
- Основная кнопка отражает действие: «Запустить», «Пауза», «Продолжить», «Следующий шаг» или «Убрать черновик».
- По умолчанию следующие шаги отправляются автоматически. Можно включить подтверждение каждого шага.
- Шесть настроек: автоматический переход, задержка 1/3/5/10 секунд, ожидание ответа 15/30/60/120 минут, сохранение включённого экрана, подсветка и компактная панель. По умолчанию: автоматический переход, 3 секунды, 120 минут, остальные три переключателя включены.
- Понятные разделы «План», «История», «Настройки» и короткие объяснения действий. Служебная инструкция в команде сокращена.
- «Убрать черновик» доступно после остановки до отправки. Удаляется только собственный неизменённый текст, в том числе оставшийся от 0.4.2. Проверка пустого поля возвращает возможность запуска этого шага; автоматического запуска после очистки нет.
- Собственный клик отправки больше не принимается за вмешательство пользователя при совпадении окна и кнопки в коротком допустимом интервале.

Следующий шаг разрешается только после уникальной итоговой отметки текущего задания, завершения генерации и восьми секунд стабильного результата. Затем действует выбранная задержка. Вопрос к владельцу, ошибка, блокировка телефона, смена чата или неясный исход отправки останавливают очередь. Уже зафиксированная попытка отправки автоматически не повторяется.

## Обновление и короткий тест

1. Установи APK поверх 0.4.2, без удаления приложения. Идентификатор и сертификат сохранены, versionCode повышен до 8.
2. Открой Директор обычным значком. В «Настройки → Поведение и оформление» выбери параметры и сохрани их.
3. Нажми «Открыть ChatGPT и панель». Закрой панель крестиком, уйди из ChatGPT и вернись: она должна остаться скрытой.
4. Верни панель из Директора. В тестовой беседе с пустым полем запусти план из трёх коротких шагов. При включённом автопереходе дополнительные нажатия между успешно завершёнными шагами не нужны.
5. Проверь «Пауза» и ×: дальнейшая отправка прекращается, синяя рамка исчезает. Если служба после обновления не подключилась, выключи и включи её один раз в специальных возможностях Android.

## Проверено

350 JVM-проверок и сценариев: Core 109, ManualQueue 38, lifecycle 8, WindowChrome 14, AutoGuard 64, DraftRecovery 22, ChatSurface 16, FailureReport 13, настройки 32, типы хранилища 34. Android-объекты в этих проверках подставные; это не тест интерфейса на устройстве.

Собраны оба варианта приложения. Проверены подпись v2/v3, zipalign, целостность ZIP и скомпилированные manifest/DEX. Новых разрешений нет. Сертификат совпадает с предыдущим выпуском.

Владелец подтвердил работу предыдущей версии 0.4.2 на телефоне. Новая панель, её отображение и цикл автоочереди 0.4.3 ещё требуют проверки на realme. Эмулятор не использовался. Нужны открытое официальное приложение ChatGPT и разблокированный телефон. Сборка сохраняет тестовую подпись; мини-ИИ в неё не входит.
