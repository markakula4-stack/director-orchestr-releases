# Директор-оркестратор

Сайт и публичные Android-сборки: https://director-orchestr.pages.dev/

Текущая версия: **0.4.8-preview**. Ожидание восстановления поля между шагами и точная ручная проверка отправки. Подробности и ограничения — [заметки выпуска](releases/v0.4.8-preview/NOTES.md).

## Установка

Скачай APK с сайта и установи поверх предыдущего Директора. Package `app.hashqueue`, прежняя тестовая подпись, versionCode 14. План и настройки кодом обновления не удаляются. Старую незавершённую отправку нужно проверить; её автоматического повтора не будет.

Под кнопкой открытия выбранного чата выбери «После ответа → Автоматически». Открой нужную беседу и нажми «Запустить» на панели. Режим «Вручную» ждёт нажатия после каждого распознанного ответа. В чат отправляется только введённая команда; включить служебную приписку больше нельзя.

## Публикация

Сайт находится в `site/`. APK из `releases/<tag>/` публикуется в GitHub Releases; точная копия расположена в `site/downloads/`. `latest.json` содержит размер и SHA-256. GitHub Actions проверяет файлы и подпись метаданных скачивания, публикует сайт в существующий Cloudflare Pages проект, затем скачивает оба APK и сравнивает их байты. Источник Android-приложения поставляется отдельным архивом; автоматический Source code архив GitHub содержит только сайт и файлы этого репозитория.

0.4.6 отозвана по запросу владельца и не публикуется повторно. Её старая ссылка на сайте ведёт на текущий APK; GitHub-тег и релиз удалены. История Git не переписывалась.

Проверки: `node scripts/validate-site.mjs` и `node --test scripts/publish-release.test.mjs`.

Работа живого интерфейса зависит от доступных Android-элементов выбранного приложения. Проверки на JVM не заменяют проверку на физическом телефоне. Эмулятор не использовался.
