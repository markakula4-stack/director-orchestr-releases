# Директор-оркестратор

Публичные выпуски Android-приложения и исходники сайта загрузки.

- Сайт: https://director-orchestr.pages.dev/
- APK 0.2.0-preview: https://github.com/markakula4-stack/director-orchestr-releases/releases/tag/v0.2.0-preview
- [Подключение автопубликации и реальный тест](docs/SETUP_RU.md)

Файлы сайта находятся в `site/`, APK — во вложениях GitHub Releases. Исходники Android-приложения в этот репозиторий не загружены. Автоматические архивы Source code на странице выпуска относятся к файлам репозитория, а не к установщику Android.

## Публикация сайта

Сценарий **Deploy site to Cloudflare** запускается при изменении `site/`, `scripts/` или самого сценария в ветке `main`. Его также можно запустить вручную на вкладке Actions. Перед первым запуском нужны два секрета Cloudflare. После их добавления изменение файлов в main запускает реальную публикацию; доступен и ручной запуск.

После локальной проверки сценарий подтверждает существующий проект `director-orchestr`, использует его фактическую production-ветку и публикует сайт без пересоздания проекта. Проверка после публикации сравнивает живые файлы с коммитом, проверяет старую ссылку скачивания и скачивает APK с проверкой размера и SHA-256.

Локальная проверка: `node scripts/validate-site.mjs` (Node.js 24).

## Статус приложения

0.2.0-preview — базовая очередь с ручным переносом сообщений и тестовой подписью. Автоматическая отправка сообщений и мини-ИИ пока не реализованы. Автопубликация сайта не является автообновлением APK на телефоне.
