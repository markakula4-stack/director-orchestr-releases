# Директор-оркестратор

Публичные выпуски Android-приложения и исходники сайта загрузки.

- Сайт: https://director-orchestr.pages.dev/
- APK 0.4.0-preview: https://github.com/markakula4-stack/director-orchestr-releases/releases/tag/v0.4.0-preview
- [Подключение автопубликации и реальный тест](docs/SETUP_RU.md)

Файлы сайта находятся в `site/`. Проверенный APK хранится в `releases/<tag>/` и публикуется во вложениях GitHub Releases перед обновлением сайта. Основные кнопки скачивают ту же сборку непосредственно с Cloudflare из `site/downloads/`; GitHub сохранён как запасная ссылка. `latest.json.apkUrl` — исходный GitHub-адрес, `downloadUrl` — прямая загрузка с сайта. Исходники Android-приложения в этот репозиторий не загружены. Автоматические архивы Source code на странице выпуска относятся к файлам репозитория, а не к установщику Android.

## Публикация сайта

Сценарий **Deploy site to Cloudflare** запускается при изменении `site/`, `releases/`, `scripts/` или самого сценария в ветке `main`. Его также можно запустить вручную на вкладке Actions. Перед первым запуском нужны два секрета Cloudflare. После их добавления изменение файлов в main запускает реальную публикацию; доступен и ручной запуск.

Сначала отдельное задание проверяет размер и SHA-256 APK, создаёт preview-релиз и загружает файл. Повторный запуск не перезаписывает уже опубликованный APK: содержимое должно совпасть. Только после успешной публикации APK сценарий подтверждает существующий проект `director-orchestr`, использует его фактическую production-ветку и публикует сайт без пересоздания проекта. Проверка после публикации сравнивает живые файлы с коммитом, проверяет старую ссылку скачивания и скачивает APK с обоих адресов с проверкой размера и SHA-256. Для прямой загрузки дополнительно проверяются заголовки файла, HEAD и продолжение скачивания через HTTP Range.

При выпуске новой версии скопируй подписанный APK также в `site/downloads/` с тем же именем, обнови `downloadUrl` и пять основных кнопок. Проверка сравнивает каждую размещённую копию с исходным APK в `releases/`; незнакомые и отличающиеся APK не публикуются. Старые версии в `site/downloads/` можно сохранять, чтобы ссылки продолжали работать.

Локальная проверка: `node scripts/validate-site.mjs` (Node.js 24).

## Статус приложения

0.4.0-preview объединяет светлый нативный Glass 04 и экспериментальную автоочередь для официального Android-приложения ChatGPT. До 20 шагов, ручной режим, журнал и сохранение прогресса остаются. Доступ к тексту и кнопкам ChatGPT включается пользователем в специальных возможностях Android; запуск — кнопкой «Старт» в выбранном чате. При блокировке, смене чата, ошибке или неясном исходе очередь останавливается. Повторная отправка при неизвестном исходе не выполняется.

У приложения нет сетевого разрешения. Автоочередь работает только при открытом ChatGPT и разблокированном телефоне. Сборка использует прежний тестовый ключ. Эмулятор для этого выпуска не запускался; проверка интерфейса и автоочереди на Android 16/realme ещё требуется. Мини-ИИ и работа при заблокированном экране не реализованы. Автопубликация сайта не является автообновлением APK на телефоне.
