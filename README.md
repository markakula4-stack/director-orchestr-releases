# Директор-оркестратор

Публичные выпуски Android-приложения и исходники сайта загрузки.

- Сайт: https://director-orchestr.pages.dev/
- APK 0.3.1-preview: https://github.com/markakula4-stack/director-orchestr-releases/releases/tag/v0.3.1-preview
- [Подключение автопубликации и реальный тест](docs/SETUP_RU.md)

Файлы сайта находятся в `site/`. Проверенный APK хранится в `releases/<tag>/` и публикуется во вложениях GitHub Releases перед обновлением сайта. Исходники Android-приложения в этот репозиторий не загружены. Автоматические архивы Source code на странице выпуска относятся к файлам репозитория, а не к установщику Android.

## Публикация сайта

Сценарий **Deploy site to Cloudflare** запускается при изменении `site/`, `releases/`, `scripts/` или самого сценария в ветке `main`. Его также можно запустить вручную на вкладке Actions. Перед первым запуском нужны два секрета Cloudflare. После их добавления изменение файлов в main запускает реальную публикацию; доступен и ручной запуск.

Сначала отдельное задание проверяет размер и SHA-256 APK, создаёт preview-релиз и загружает файл. Повторный запуск не перезаписывает уже опубликованный APK: содержимое должно совпасть. Только после успешной публикации APK сценарий подтверждает существующий проект `director-orchestr`, использует его фактическую production-ветку и публикует сайт без пересоздания проекта. Проверка после публикации сравнивает живые файлы с коммитом, проверяет старую ссылку скачивания и скачивает APK с проверкой размера и SHA-256.

Локальная проверка: `node scripts/validate-site.mjs` (Node.js 24).

## Статус приложения

0.3.1-preview — очередь до 20 шагов, новый редактор и исправление утечки окна при пересоздании экрана. Ручной перенос сообщений и тестовая подпись сохраняются. Пройдены 151 проверка логики и хранения данных и 6 начальных UI-проверок Android 9. Полный Android-прогон и повторная проверка исправления не завершены. Автоматическая отправка сообщений и мини-ИИ пока не реализованы. Автопубликация сайта не является автообновлением APK на телефоне.
